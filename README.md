# 📊 Power BI Projects Portfolio

This repository contains two interactive data visualization projects developed using **Microsoft Power BI**. These projects demonstrate data visualization, reporting, data analysis, and dashboard development skills.

## 🚀 Projects

### 1. Sales Analysis Dashboard

**Project File:** [Sales Report.pbix](https://github.com/Rhushipatil/Powerbi_Sales/blob/main/Sales%20Report.pbix)

**Description:**

An interactive Power BI sales reporting project designed to organize and visualize sales data. The report provides a dashboard-based approach to understanding sales performance and exploring business data.

**Objectives:**
- Analyze sales data through interactive visualizations.
- Present business information using charts and graphs.
- Make sales data easier to understand.
- Support data-driven business decisions.

**Tools & Technologies:**
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

### 2. Student Data Analysis Dashboard

**Project File:** [Power BI Student Data.pbix](https://github.com/Rhushipatil/Powerbi_Sales/blob/main/powerbi%20student%20data.pbix)

**Description:**

A Power BI data visualization project focused on student-related data. It demonstrates how student information can be transformed into meaningful visual reports for understanding and analyzing academic data.

**Objectives:**
- Analyze student-related information.
- Organize and visualize student datasets.
- Present data through interactive reports.
- Identify useful patterns in student data.

**Tools & Technologies:**
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 🛠️ Skills Demonstrated

- Data Cleaning and Transformation

## ▶️ How to Run the Projects

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Download the required `.pbix` file.
4. Open the file using Power BI Desktop.
5. Explore the reports and visualizations.
